# Changelog

Notable project changes are recorded here. Dates are intentionally omitted until a
release is published.

## Unreleased — MVP

- Added FastAPI API, CLI, PostgreSQL/pgvector schema, and migrations.
- Added item capture, revisions, chunking, hybrid search, and an asynchronous indexing
  and ingestion worker.
- Added text, Markdown, PDF, and guarded public URL ingestion with folder polling.
- Added wiki-link graph, related and forgotten connections, timeline, and decision log.
- Added a dark graph-inspired web UI, local Docker Compose stack, CI, tests, and a small
  retrieval smoke fixture.
- Documented that live Supabase connectivity/migration and production hardening remain
  unverified or out of scope.
